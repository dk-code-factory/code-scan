What the fair comparison shows

On scylladb/nodejs-rs-driver every Codex and Opus effort level ran on the same 995KB at the same commit, with 40KB chunks:

  • Most findings for little money: Codex xhigh, 74 confirmed at $0.75/100KB, or Codex max, 78 at $0.86. Codex medium costs least per confirmed finding ($0.07) but finds only 41.
  • Most raw findings, not the best: Opus max, 86 confirmed at $5.89/100KB, about 7× Codex max. Its extra findings are mostly low severity once triage re-graded them (22 low, 16 high, against 8 low, 20 high for Codex max; see conf. columns under Columns: Findings by severity), so its recall is lower: 0.35, against 0.40 for Codex xhigh and 0.41 for max. Recall = severity-weighted share of the 217 issues any scan confirmed; no single scan reaches half.
  • Most coverage: run several scans. All six Codex levels together reach recall 0.76 for $35 in total; Opus max + Codex xhigh reaches 0.66 for $66; all four Opus levels only 0.45 for $88. More combinations in Pick effort.
  • Quickest: Opus low to high, 16–41 reviewer-minutes (summed agent time) for the 995KB, against 93–217 for Codex and 231 for Opus max. Wall clock ranks them the same (4–11 min against 24–53 and 80), but parallelism was not recorded, so treat it as approximate. They confirm only 29–39.

Confirmed = an auto-triage agent agreed (see note below). For a recommendation see Pick a provider, Pick a model and Pick effort.

All configurations

Confirmed and false positive are verdicts of an auto-triage agent, mostly Codex, that re-read each finding against the code: read them as an agent's agreement, not reproduced bugs. Codex may judge its own findings leniently. Price is the API list price of every token of every reviewer agent, cached input at the cache-read rate. Details in Method & data.

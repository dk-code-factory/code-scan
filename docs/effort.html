Pick an effort level

Ten full scans of one ~1MB TypeScript + Rust codebase, all on the same commit with the same 40KB chunks: Codex gpt-6.1-sol at low → ultra and Opus 5.5 at low → max, all triaged by the same judge (Codex gpt-6.1-sol at high effort).

Effort levels are each provider's own scale: Codex high is not the same setting as Opus high, and Codex has ultra, which Opus lacks. Compare levels within a provider. Opus xhigh exists but was not measured.

Recall: higher = finds more of the known bugs, weighted by severity. Details: share of the 217 distinct confirmed issues found by any of the ten runs, weighted critical 4, high 3, medium 2, low 1. Bugs no run found are not counted, so true recall is lower. Being weighted, it can rank runs differently from their raw confirmed counts.

Prices are per 100KB of code reviewed and cover the review agents only. The judge's triage is extra: about $0.03 per finding it checks, so it grows with the number of findings (31–88 per scan here). Agent-min = reviewer time summed over all agents for the whole ~1MB scan; your wall clock depends on how many reviewers you run at once.

Findings

Read these as trends, not exact numbers. One codebase, one run per level, and the judge is a Codex model, which may favour Codex findings. Treat recall differences of about 0.05 or less as noise.

Codex: xhigh is the sweet spot. Skip max and ultra.

Recall rises with effort up to xhigh: 0.17 at low ($0.24/100KB), 0.23 medium ($0.30), 0.31 high ($0.43), 0.40 xhigh ($0.75). Each step adds 0.06–0.09, just above the noise line; together low → xhigh more than doubles. Past that, max (0.41, $0.86) and ultra (0.36, $0.95) cost more with no gain beyond noise. Here xhigh came to about $0.10 per confirmed bug; that figure depends on how buggy the code is, so use it only to compare levels.

Opus: low, medium and high find about the same. max costs five times as much as high for twice the recall.

Opus scored 0.12, 0.15 and 0.17 at low, medium and high ($0.78 → $1.20/100KB), differences within noise, so if you scan with Opus, take the cheapest, low. max doubled recall to 0.35 and confirmed the most findings of any run (85 vs 78 for Codex max, the next most), but cost $5.89/100KB, eight times Codex xhigh, which still scored higher recall (0.40).

Higher effort did not add false positives.

Precision stayed at 0.94–0.99 at every level of both models: higher effort found more real bugs at the same hit rate. The judge is a Codex model, so read this as "few obvious false positives", not as a measured error rate.

A second run beats a bigger one.

No single run reached more than 0.41 recall. For critical code, run Codex xhigh and max as two separate scans: together 0.55 for $1.61/100KB, more than any single run at any price. On a budget, high + xhigh (0.49, $1.18/100KB) also beats every single run. All six Codex runs together reach 0.76 ($3.54/100KB); Codex xhigh + Opus max reach 0.66, because Opus max found far more issues no other run found (37, confirmed or not; no other run more than 16), but cost $6.64/100KB. Every pair tested mixed two levels; running the same level twice was not measured.

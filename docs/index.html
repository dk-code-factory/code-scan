How to pick a model

By language

What was measured per language. "Compared" means two or more models reviewed the same code; elsewhere only one model ran, so the general recommendation applies. Prices are at the recommended levels (Codex xhigh, Opus medium) plus the scans run without an explicit effort; those Codex scans used the CLI default, high.

In general

Default for full scans: Codex gpt-6.1-sol at xhigh effort.

On every repository where it ran next to a Claude model on the same code it found the largest severity-weighted share of issues (gocql 0.76 vs Fable 0.43; seastar 0.81 vs Opus 0.30; scylla-rust-driver 0.59 vs Fable 0.55), at $0.27–0.52 per 100KB — about a seventh of Fable's price on the same 2.7MB of Rust. Auto-triage confirmed ≥ 0.99 of its findings, but that triage was also done by Codex and rejected almost nothing (4 false positives in 1,623 Codex verdicts), so treat that figure as an upper bound.

Best Claude reviewer: Opus 5.5 at 20KB chunks.

Found all 7 known bugs on the gocql benchmark at $1.19/100KB and topped the calibration sample of the private Go project (0.74). Full scans cost $0.38–0.73/100KB with 0.81–1.00 precision after triage. Use it when you want a Claude-only pipeline or as the second opinion next to Codex.

Fable 5.2: strongest on small samples, most expensive at scale.

Best quality on the seastar and gocql calibration samples (0.65, 0.49), but $1.93/100KB on the full scylla-rust-driver scan — about seven times Codex and five times Opus on the same repository. Worth it for a focused scan of a critical subsystem (--only), not for a whole large repo.

Sonnet 5.5: cheap but inconsistent. Haiku 5.5: don't use for review.

Sonnet ranged from 0.68 (private Go) to 0.09 (seastar C++) on calibration samples, and found 4 of 7 known gocql bugs. Haiku found 2 of 7, scored 0.00–0.32 and had rounds fail because reviewers left files unsubmitted.

For critical repos, run two models side by side.

Overlap between models is small: of the issues Codex and Fable found on gocql only 25 were found by both, on scylla-rust-driver only 12. In the effort study below, Codex xhigh alone found 0.40 of the confirmed issues and 0.66 together with Opus max. start --profile codex-default,opus-default runs both on the same commit and plan; compare shows what only one found.

Recall = share of the 217 confirmed issues all ten runs found together on nodejs-rs-driver (TypeScript + Rust). Effort was measured on that one repository; the trend (recall up, precision flat) is what to expect elsewhere, not the exact numbers.

Details

Ten full scans of scylladb/nodejs-rs-driver (995KB, 129 files) on one commit, sharing one plan and 40KB chunks: Codex gpt-6.1-sol at low → ultra and Opus 5.5 at low → max. Every finding was triaged by the same judge. Recall is measured against all 217 confirmed issues the ten runs found together.

Codex: use xhigh. Use high on a tight budget. Skip ultra.

Recall rises steadily with effort up to xhigh: 0.17 at low ($2.41), 0.23 medium, 0.31 high ($4.28), 0.40 xhigh ($7.49). max adds almost nothing (0.41 for $8.54), and ultra found less (0.36) for more money ($9.44). xhigh costs $0.75 per 100KB and about $0.10 per confirmed bug.

Opus: low, medium and high find about the same. max costs five times as much for twice the recall.

Opus scored 0.12, 0.15 and 0.17 at low, medium and high ($7.72 → $11.93), so if you scan with Opus, low or medium is enough. max doubled recall to 0.35 but cost $58.61 ($5.89/100KB, 1.4M output tokens), eight times Codex xhigh, which found more.

Effort does not change the false-positive rate.

Precision stayed at 0.94–0.99 at every level of both models: higher effort finds more real bugs, not cleaner ones. Codex reports most issues as high and Opus rates them lower; after triage both land mostly on medium (see the severity table).

A second run beats a bigger one.

No single run found more than 41% of the confirmed issues. Codex high + xhigh together reach 0.49 for $11.77, more than any single run at any price. Codex xhigh + Opus max reach 0.66, and all six Codex runs together reach 0.76 for $35. For critical code, run xhigh plus one different configuration rather than going to max/ultra.

One repository, one run per level, and a Codex judge (which may favour Codex findings), so treat differences under ~0.05 as noise.

How to pick a chunk size

Let init calibrate it — and expect 20–40KB.

Review quality falls off sharply once a reviewer gets too much code at once. Across the 12 calibration curves below, the best-scoring size was 20KB or 40KB in 9, and in 8 quality fell by a quarter or more one step past it (Fable on seastar: 0.78 at 40KB → 0.39 at 60KB). Only one run peaked above 60KB: Opus on cpp-rs-driver, at 90KB. Calibration costs $1–5 per model for Sonnet and Opus, $7–15 for Fable, and is reused by every later scan.

Install

# Claude Code
/plugin marketplace add dk-code-factory/code-scan
/plugin install code-scan@code-scan

# Codex CLI
codex plugin marketplace add dk-code-factory/code-scan
codex plugin add code-scan@code-scan

# Any Agent Skills host
git clone https://github.com/dk-code-factory/code-scan && node code-scan/bin/code-scan.js install

Then run /code-scan:init once per repository: it benchmarks models on a sample of that repo and picks a chunk size for each.

Method

  • All numbers come from local code-scan stores (~/.cache/code-scan) via npm run site (bin/site-export.js), which runs the tool's own scans, compare, init report and calibrate report on copies of the stores. Only counts, sizes, models and dollars are exported; private repositories are anonymized.
  • Price is list price of every token of every reviewer agent (preamble, coordination turns, re-reads), not just the code. Scans whose transcripts are gone or incomplete show no price.
  • Precision counts only triaged findings. Most triage was done by Codex auto-triage, which may favour Codex findings.
  • Each comparison is one run; model sampling varies between runs.
  • Codex scans before the effort study ran without --effort, so they used the Codex CLI default, high; Claude scans without an effort ran at Claude Code's default.

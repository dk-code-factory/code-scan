code-scan

Repository-wide bug scanning with parallel reviewer agents from Claude Code, Codex, Gemini, Antigravity, Copilot, Cursor or OpenCode. These pages show how reviewer models performed on real repositories and which to pick.

What do you want to decide?

OpenAI or Anthropic?Codex vs Claude on the same code: share of issues found, price, precision. Which model?Opus, Fable, Sonnet, Haiku and Codex by language, the known-bug benchmark and chunk size. Which effort level?low → ultra on one repository: what more effort buys and where it stops paying. Compare everythingEvery full scan as a sortable row with price, findings, false positives and time; plot any two measures.

Find your setup

Pick the language of the code you scan and what matters most to you: price, number of findings, findings per dollar or speed. The recommendation comes from the scans below; the evidence list shows what was actually measured on that language.

Install

# Claude Code
/plugin marketplace add dk-code-factory/code-scan
/plugin install code-scan@code-scan

# Codex CLI
codex plugin marketplace add dk-code-factory/code-scan
codex plugin add code-scan@code-scan

# Any Agent Skills host
git clone https://github.com/dk-code-factory/code-scan && node code-scan/bin/code-scan.js install

Then run /code-scan:init once per repository: it benchmarks models on a sample of that repo and picks a chunk size for each.

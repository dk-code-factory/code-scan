Everywhere both providers reviewed the same code, Codex found the larger share of issues, and at a lower price per 100KB than any Claude model except Sonnet and Haiku.

Pick Anthropic when you need a Claude-only pipeline: Opus 5.5.

Opus found all 7 known bugs on the gocql benchmark and has 0.81–1.00 precision after triage. Fable 5.2 finds more on small samples but costs several times as much at scale. See Pick a model.

For critical code, use both.

The providers overlap little: in the effort study Codex xhigh alone found 0.40 of the confirmed issues and 0.66 together with Opus max. start --profile codex-default,opus-default runs both on the same commit and plan; compare shows what only one found.

Most triage was done by Codex auto-triage, which may favour Codex findings (4 false positives in 1,623 Codex verdicts), so read Codex precision as an upper bound.

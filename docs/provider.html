The numbers in this table come from one test: ten scans of the same 995KB TypeScript + Rust repository, Codex at six effort levels and Opus at four, every finding triaged (mostly by Codex auto-triage, which rejects almost nothing). Pick OpenAI (Codex gpt-6.1-sol at xhigh) for full scans.

Why Codex: in all three head-to-head full scans it found the larger share (0.81 vs Opus 0.29, 0.76 vs Fable 0.43, 0.59 vs Fable 0.55) and, where both prices were recorded, cost less. Share counts only the issues the two scans found between them, so it runs higher than recall in the effort test (measured against everything ten runs found); the two are not comparable. Part of the gap, in share and in effort-test recall, comes from Codex rating findings more severe (Severity labels). Which effort: xhigh is where recall stops climbing in the effort test (0.40 at $0.75 per 100KB); to save money, high (the Codex default) gets 0.31 at $0.43. Codex against Opus rests on one full scan and the effort test.

Pick Anthropic when you need a Claude-only pipeline: Opus 5.5.

On a small benchmark (107KB of Go, 7 known bugs) Opus at default effort found all 7 (Fable 6, Sonnet 4, Haiku 2). That sample is small: on the 995KB effort test Opus found only 0.12–0.17 of the confirmed issues (severity-weighted) below max, no more than Codex low (0.17). So run Opus at max: it doubles recall (0.35 vs 0.17 at high) for about 5x the price ($5.89 vs $1.20 per 100KB) and 80 minutes wall clock. Fable 5.2 costs more: $1.93 per 100KB in its one priced full scan, against $0.38–$0.73 for Opus at default effort on other repositories (All full scans). Sonnet and Haiku are cheaper but missed most of the known bugs. See Pick a model.

For critical code, use both.

The two providers mostly find different issues: Codex xhigh alone found 0.40 of the confirmed issues (severity-weighted), merged with Opus max 0.66, at $6.64 instead of $0.75 per 100KB. Register one profile per configuration, then start both on the same commit (code-scan.js commands; the /code-scan:profiles and /code-scan:scan skills do the same):

code-scan.js profile register codex-xhigh \
  --prompt default --model codex:gpt-6.1-sol --effort xhigh --chunk-kb 40
code-scan.js profile register opus-max \
  --prompt default --model opus --effort max --chunk-kb 40
code-scan.js start --profile codex-xhigh,opus-max

A bare model name such as opus runs on Claude Code (opus = Opus 5.5; a full id like claude-opus-5-5 also works); a runner: prefix such as codex: picks another CLI. --chunk-kb 40 (KB of code per reviewer agent) matches the effort test; other chunk sizes were not tested for this pair. code-scan.js compare then shows what only one of them found.

Codex vs Opus, every effort level

Price on the same code: Opus costs about 3x as much as Codex per 100KB at low–high ($0.78–$1.20 vs $0.24–$0.43) and about 7–8x at max ($5.89 vs $0.75–$0.86 for Codex xhigh/max).

Recall is measured against the issues these ten runs found and triage confirmed, not against every bug in the code. One run per level, so small gaps (Codex max 0.41, xhigh 0.40, ultra 0.36) may be run-to-run noise. Wall clock depends on how many reviewer agents ran in parallel and how many failed and were retried more than on effort. Merged row: * wall clock is the slower of the two runs, if both run at once; † $/confirmed bug not computed for the merged pair. More on effort levels: Pick effort.

Full scans of the same code

Two full scans of one repository, compared only on files both reviewed with identical content. Share = share of all distinct issues either scan found, weighting critical 4, high 3, medium 2, low 1; an issue both found counts for both, so the two shares add up to more than 1. Share counts every reported finding, confirmed or not; on these files triage rejected at most 6 findings per scan. Only seastar has an Opus full scan next to Codex; the other two pair Codex with Fable 5.2.

$/100KB is for each whole scan, which covered more than the compared files. Codex "default" is the Codex CLI default effort; Claude "default" means no effort was set. "–" = price not recorded.

Severity labels

The same pairs (share is in the table above), findings on the compared files split by the severity each reviewer gave. Codex labels almost nothing low; Claude models label many findings low. Share weights each issue by its highest label, so part of Codex's lead in share comes from how it labels severity, not only from finding more. "Only this one" counts findings the other scan did not report: in every pair most findings were found by one model only, which is why merging two scans finds more.

All full scans

How much data stands behind each model: every full scan in the data set, on different repositories per model. Because the code differs, don't compare price or findings across rows here; use the effort test for that. Price varies by repository, which is why Opus here ($0.38–$0.73) can come in below Opus low in the effort test ($0.78).

Code reviewed and findings are summed over scans, so a repository scanned more than once counts each time. $/100KB covers default-effort scans with a recorded price. Precision = confirmed / (confirmed + false positive) among triaged findings.
